# Wiki Schema

This is the LLM-maintained wiki for Pastel Sketchbook. You (the LLM) own this
directory. You create, update, and cross-reference all pages. The user reads;
you write.

## Architecture

```
wiki/
  AGENTS.md          # This file. Schema and operating instructions.
  llm-wiki.md        # Reference: the LLM Wiki pattern (read-only).
  index.md           # Content-oriented catalog of every wiki page.
  log.md             # Append-only chronological record of operations.
  videos/            # Video wiki. One page per category + index.
    index.md         # Video-specific index with stats and category links.
    {category}.md    # Per-category page (korea, finance, kubernetes, etc.)
    details/         # Per-video detail pages with AI-generated summaries.
      {video-id}.md  # Transcript summary, key takeaways, topics, related videos.
    tags/            # Topic-based grouping, generated by generate-wiki.ts.
      index.md       # All topics with counts and links (topics shared by 2+ videos).
      {topic}.md     # Videos grouped by topic, linking to detail pages.
```

## Raw Sources

- `homepage/public/videos-metadata.json` -- generated by `sync-videos.ts`.
  Contains `{ videos: [{ id, title, views, date, tags[] }], generatedAt, count }`.
- `homepage/src/config/videos.ts` -- canonical category-to-videoId mapping.
  Categories: korea, finance, kubernetes, development, security, programming.

These are immutable from the wiki's perspective. Never modify raw sources.

## Page Conventions

### Frontmatter

Every wiki page (except AGENTS.md and log.md) uses YAML frontmatter:

```yaml
---
type: index | category | topic | synthesis | query-result | video | tag
category: korea | finance | kubernetes | development | security | programming
tags: [tag1, tag2]
sources: 17          # number of source videos on this page
updated: 2026-04-05  # last generation/edit date
---
```

Video detail pages (`type: video`) add extra frontmatter:

```yaml
---
type: video
videoId: VIDEO_ID
category: development
tags: [rust, tokio]
views: 2900
date: 2026-04-03T...
summarized: 2026-04-06T...   # when the summary was generated
---
```

### Cross-references

Use wiki-style links: `[page title](relative-path.md)`.
Every category page links back to `index.md` and to related categories.
When titles or tags overlap across categories, add "See also" cross-references.

### Topic Clusters

Within each category page, group videos by topic cluster derived from titles
and tags. A cluster is 2+ videos sharing a theme (e.g., "AKS Networking",
"Service Mesh", "AI/ML"). List clusters after the summary, before the full
video table.

## Operations

### Ingest

Triggered automatically by `bun scripts/generate-wiki.ts` after video metadata
sync. The script:

1. Reads `videos-metadata.json` and `videos.ts` config.
2. Generates/overwrites per-category pages with frontmatter, topic clusters,
   video tables, top tags, and cross-references.
3. Updates `wiki/videos/index.md` with stats and category summaries.
4. Loads all detail pages and computes related videos using Jaccard similarity
   on topic tokens (word-level decomposition for matching, compound topics for
   tag page generation). Upserts a `## Related Videos` section in each detail
   page and includes the related list in the wiki bundle.
5. Generates `wiki/videos/tags/` pages for topics shared by 2+ videos, plus
   a topic index page.
6. Appends an entry to `wiki/log.md`.

After auto-generation, the LLM may further enrich pages during conversation:
add synthesis sections, note trends, flag contradictions, add cross-references
between categories.

### Video Details

Triggered by `task wiki:details` (or `bun scripts/generate-video-details.ts`).
Generates per-video detail pages in `wiki/videos/details/`:

1. Selects videos (default: top 10 by views; supports `--all`, `--category`, `--id`).
2. Fetches YouTube transcript via `yt-transcript` CLI (`tools/yt-transcript/`).
3. Writes scaffold page to `wiki/videos/details/{video-id}.md` with frontmatter,
   embedded transcript, and tag links. Summary enrichment (key takeaways, topics
   covered) is performed by the LLM from raw transcripts, not by Gemini.
4. Incremental: skips existing pages unless `--force` is passed.
5. Appends to `wiki/log.md`.

Note: The `## Related Videos` section in detail pages is managed by
`generate-wiki.ts`, not by the detail generation script. After generating
new detail pages, always re-run `generate-wiki.ts` to compute and upsert
related video links.

### Query

When the user asks a question about videos:

1. Read `wiki/videos/index.md` to find relevant category pages.
2. Read relevant category pages and locate matching videos/clusters.
3. Synthesize an answer with citations (`[title](https://youtu.be/ID)`).
4. If the answer is valuable, file it as a new page (e.g., `wiki/videos/topic-X.md`)
   and update the index.

### Lint

Periodically check for:

- Orphan pages with no inbound links.
- Missing cross-references between related categories.
- Stale stats (compare frontmatter `updated` to `generatedAt` in metadata JSON).
- Topic clusters that span categories (should get their own cross-category page).
- Tags that appear across multiple categories (potential synthesis opportunity).

## Log Format

Entries in `log.md` start with a parseable heading:

```
## [YYYY-MM-DD] operation | Description
```

Operations: `ingest`, `query`, `lint`, `enrich`.

Grep-friendly: `grep "^## \[" wiki/log.md | tail -5`
