## Summary

This video introduces the Azure Enterprise Edge Lab, a one-click deployable security sandbox for testing enterprise-grade Azure security across the full stack. The architecture is built on three pillars: Azure Front Door Premium with integrated WAF for edge protection, dual-region Azure Container Apps with automated failover for resilient compute, and Microsoft Sentinel Analytics with Azure Workbooks for automated SOC integration. The entire environment deploys via Bicep and the Azure Developer CLI (azd).

## Key Takeaways

- The lab provides a one-click deployment via Bicep and Azure Developer CLI (azd) for a complete enterprise security testing environment.
- Edge protection uses Azure Front Door Premium with deep WAF integration to defend against sophisticated attacks at the network perimeter.
- Dual-region Azure Container Apps with automated failover routing ensure operational continuity during regional service disruptions.
- The automated SOC layer leverages Microsoft Sentinel Analytics and Azure Workbooks for proactive threat management and streamlined visibility.
