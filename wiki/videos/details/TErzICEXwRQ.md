# Modular Playbook for Vertical Project Delivery

> [development](../development.md) · 6 views · Aug 11, 2026
> [Watch on YouTube](https://youtu.be/TErzICEXwRQ)

## Summary

This talk presents a modular playbook for vertical project delivery built around iterative agentic coding, where a layered architecture — foundation, integration, and four deepening AI iteration cycles — systematically absorbs rapidly improving AI capabilities. It argues for front-loaded preparation (executable specifications, data contracts, and a layer-zero playbook) combined with a hybrid vertical iteration model that runs one deep agentic push per project across a 6-month window, while a continuously advancing shared platform track prevents agents from re-solving identical problems.

## Key Takeaways

- Front-loading high-leverage preparation in layer zero — problem statement, non-goals and success metrics, prioritized jobs-to-be-done, ADRs, API contracts and event schemas, plus a runnable skeleton with an evaluation harness — prevents agent thrashing caused by ambiguous goals and missing context.
- Pure horizontal delivery spreads teams thin across half-baked projects, and pure sequential delivery risks missing new model gains; the hybrid vertical iteration model staggers deep agentic pushes one project at a time while layer-zero prep runs in parallel across all projects.
- A thin shared platform track — auth services, observability stack, CI templates, evaluation harness, and design system — advances continuously so every product track automatically benefits from platform improvements without duplicating common functionality.
- Universal delivery layers progress from foundational correctness through a working vertical slice, production-ready core, reliability/performance/observability hardening, polish and UX, to maintainability and handoff — with an evaluation gate after each layer choosing to graduate, deepen, pivot, or kill the project.
- A strategic ~6-month model-swap window lets teams harden and polish with progressively stronger AI models without restarting from zero, while hard quantifiable metrics (test coverage, latency, maintainability scores) embedded in layer zero keep completion decisions objective.
