## Summary

Stitch agent skills is an initiative designed to bridge the gap between AI-generated design and production-grade software by leveraging the Model Context Protocol (MCP). The framework allows AI agents like Claude and Cursor to move beyond generic 'AI default' outputs by injecting domain-specific UI/UX rules, structured React code construction, and programmatic video demonstrations into their context windows.

## Key Takeaways

- The MCP hub acts as a central integration layer to inject design systems, aesthetic calibration, and AST-validated code workflows directly into LLM prompts.
- Aesthetic parameters such as density, variance, and motion are programmatically enforced via a semantic design.md file, including logic constraints like forcing monospace numbers when density exceeds a specific threshold.
- The system enforces 'anti-slop' design standards by banning generic patterns like pure black or neon glows in favor of sophisticated palettes (e.g., Zinc 950) and premium typography like Geist and Cabinet Grotesque.
- A structured design-to-code pipeline transforms monolithic HTML into modular React architectures, utilizing TypeScript interfaces, custom hooks for logic separation, and automated AST validation.
- Integrated Remotion workflows enable the programmatic generation of high-fidelity MP4 walkthroughs by fetching project screens and applying physics-based transitions.
