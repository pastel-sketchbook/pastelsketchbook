## Summary

Compound Engineering is an AI-native software development philosophy that aims to reverse codebase entropy by ensuring every unit of work facilitates future development. The framework shifts the engineering focus from manual coding to architectural planning and systematic learning, utilizing specialized agent swarms to achieve exponential productivity gains.

## Key Takeaways

- The engineering effort is redistributed into an 80/20 split, where 80% of time is dedicated to planning and review, while only 20% is spent on agent-led execution.
- Codebase decay is mitigated by the 'compound' phase, where engineering 'taste' and recurring patterns are codified into a central intelligence hub like claude.md using YAML front matter.
- The workflow utilizes 'agent swarms'—specialized autonomous entities like the Security Sentinel and Performance Oracle—to perform parallelized, domain-specific code reviews and validations.
- Standardized development commands such as /workflow/plan and /workflow/work leverage git worktrees for isolated, validated execution environments that automate testing and linting.
- Maturity in this paradigm scales from Level 0 manual coding to Level 5 parallel cloud orchestration, where compute power replaces human attention as the primary development bottleneck.
