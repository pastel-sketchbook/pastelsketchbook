## Summary

This video introduces kube-log-viewer, a 100% Rust terminal UI for streaming and searching Kubernetes pod logs with keyboard-driven navigation. The tool replaces manual kubectl log commands with a continuous debugging workflow featuring visual namespace/context browsing, real-time log filtering with syntax highlighting, integrated JSON parsing, and multi-pod side-by-side streaming.

## Key Takeaways

- Built entirely in Rust for high performance and extremely low resource usage, ensuring the monitoring tool never interferes with actual workloads.
- Visual browsing of namespaces, contexts, and containers eliminates error-prone manual typing of long resource names.
- Integrated JSON parsing removes the need to pipe log output to external tools like jq, keeping the debugging flow uninterrupted.
- Multi-pod side-by-side streaming enables real-time comparison and correlation of events across infrastructure components.
