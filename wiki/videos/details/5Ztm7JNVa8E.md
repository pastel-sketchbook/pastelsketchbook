# Drasi: The Future of Change-Driven Architecture

> [kubernetes](../kubernetes.md) · 47 views · Feb 17, 2026
> [Watch on YouTube](https://youtu.be/5Ztm7JNVa8E)

## Summary

This video introduces Drasi, a change-driven architecture platform that replaces both inefficient polling and operationally heavy event-driven architectures (Kafka clusters, brittle glue code) with continuous queries that react to meaningful data changes in real time. It inverts the traditional dependency from "what is the current state?" to "what meaningful change has occurred?", streamlining the flow from data source through observation to action.

## Key Takeaways

- Polling is simple but inefficient with high latency, while event-driven architecture (EDA) solves latency but requires maintaining Kafka clusters and layers of brittle glue code.
- Drasi introduces continuous queries that focus on "what meaningful change has occurred" rather than repeatedly asking "what is the current state."
- The architecture flows from data source through observation and continuous query evaluation to automated reactions, eliminating boilerplate.
- Both polling and EDA force developers to compromise between resource efficiency and operational simplicity; Drasi eliminates this trade-off.
