## Summary

This session introduces Microsoft Data Formulator, an AI-powered visual workspace that blends natural-language intent with direct UI control over agentic data visualization. It resolves the two bottlenecks of modern exploration — data scattered across formats and questions that evolve — through connected agents, a persistent data memory vault, and spatially branching data threads. Coverage span schema-faithful grounding without hallucination, Flint's spec-to-graphic compilation across 30+ chart types, the five-step agentic workflow (connect/load/explore/refine/share), model-agnostic routing via LiteLLM, and fast open-source deployment paths from `uvx` to Docker.

## Key Takeaways

- Unify high-level intent with granular control: let analysts ask complex exploratory questions in natural language while refining calculations, branching inquiries, and formatting visuals through direct UI interactions — replacing trial-and-error prompt engineering with precise chart refinements.
- Ground agents in your data architecture: universal access connectors ingest SQL databases, S3 buckets, JSON/CSV files, and unstructured text, while the data memory vault persistently tracks relational context so downstream agents keep schema fidelity and never re-infer joins or hallucinate.
- Escape linear chat with data threads: fork any exploration point into parallel analysis paths — filter for a year while running regional comparisons and adjusting chart types — keeping the full analytical lineage visible and intact.
- Compile semantics, not boilerplate: the agent lens emits compact specifications focused on data semantics, and Flint — the specialized open-source visualization language — compiles them into publication-ready graphics with cohesive themes across 30+ chart types.
- Operate the five-step workflow end to end (connect → load → explore → refine → share): the analyst agent clarifies intent and previews sources on Databricks/S3 with human confirmation, the data agent answers with step-by-step reasoning, the style agent polishes the final 20%, and persistent sessions produce fully editable shareable reports — deploy with `uvx data-formulator` (recommended), pip, Docker Compose, or desktop builds; route models through LiteLLM to any frontier provider or on-prem inference under MIT license.
