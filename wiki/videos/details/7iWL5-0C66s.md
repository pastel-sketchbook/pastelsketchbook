# Bridging the Mainframe to the Cloud

> [kubernetes](../kubernetes.md) · 22 views · Apr 4, 2026

## Summary

This session presents a zero-impact architecture for distributing enterprise data from legacy mainframes to cloud-native environments using IBM MQ and RabbitMQ as a decoupling bridge. The approach avoids exposing expensive mainframe MIPS directly to volatile cloud workloads, instead implementing a four-part pipeline for safe extraction and real-time data distribution.

## Key Takeaways

- Direct mainframe-to-cloud connections create unpredictable costs and performance bottlenecks due to the mainframe's MIPS-based pricing model.
- IBM MQ serves as the mainframe-side message broker while RabbitMQ handles cloud-side distribution, creating a strategic decoupling layer.
- The four-part pipeline safely extracts legacy data without impacting mission-critical mainframe operations.
- This architecture enables real-time data flow between on-premises and cloud while preserving mainframe stability and data integrity.
