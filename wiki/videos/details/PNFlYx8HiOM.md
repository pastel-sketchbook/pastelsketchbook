# The Art of Git Gardening

> [development](../development.md) · 16 views · Dec 31, 2025
> [Watch on YouTube](https://youtu.be/PNFlYx8HiOM)

## Summary

This video advocates treating git commit history as a living document that requires intentional maintenance, likening it to garden care. It introduces the concept of "context debt" — the mental exhaustion from deciphering tangled merge histories — and promotes daily rebasing as a form of continuous local integration. The approach emphasizes linear history through early and frequent rebasing rather than waiting for painful end-of-sprint merges.

## Key Takeaways

- Context debt accumulates when developers delay integration, making it harder to recall logic and decipher teammates' changes in the same files.
- Daily rebasing of feature branches acts as continuous integration at the local level, keeping work linear and merge-conflict-free.
- Treating feature branches as private gardens requiring daily maintenance prevents the tangled merge commit webs that obscure project history.
- A clean linear history preserves the "why" behind code changes, making future updates and audits significantly easier.
