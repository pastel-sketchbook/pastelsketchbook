# The Agentic Future

> [development](../development.md) · 20 views · Apr 24, 2026

## Summary

This talk traces the evolution from “vector RAG” to “graph RAG” and then to agentic orchestration as enterprises try to bridge the gap between frozen model knowledge and live, proprietary data. It argues that semantic similarity alone hits a “vector wall” for multi-hop reasoning and global sensemaking, motivating knowledge graphs, community summarization, and hybrid retrieval pipelines that agents can route dynamically.

## Key Takeaways

- RAG is framed as the bridge between static pretrained knowledge and an organization’s changing internal systems; grounding reduces hallucinations by injecting up-to-date context at query time.
- Vector RAG excels at broad semantic retrieval but struggles with multi-hop reasoning, “lost in the middle” context failures, and corpus-wide summarization.
- Graph RAG shifts retrieval from “find similar chunks” to “traverse explicit relationships,” enabling causal/path explanations and global sensemaking via graph communities.
- Indexing for graph RAG requires extraction (entities/relations) plus ongoing governance (schemas/ontologies, entity resolution), which introduces non-trivial compute and maintenance cost.
- A hybrid architecture (vector + graph) plus an agentic orchestrator is presented as the practical endgame: route each query to the right tool/path at the right time.
