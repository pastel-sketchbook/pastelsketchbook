Historically, authentication  methods  like  passwords and  SMS  one-time  passcodes  have  depended on  both  the  user  and  the  server  knowing the  exact  same  piece  of  sensitive  data. The  fundamental  vulnerability  here  is simple.  If  a  secret  has  to  be  shared across  a  network,  it  can  be  intercepted, fished,  or  compromised  in  transit.
