Virtio-FS fundamentally  inverts  the  traditional fuse  security  boundary.  In  a  classic fuse  setup,  a  trusted  host  kernel delegates  operations  upward  to  an untrusted  user  space  daemon,  with  the kernel  guarding  itself  against  potential With  Virtio-FS,  this  relationship  flips completely. Because  the  guest  VM  cannot  be  trusted, the  host-side  daemon,  virtiofsd,  must actively  defend  itself  against  malicious or  malformed  file  system  commands. Direct  access,  or  DAX, optimization  transforms  how  virtual machines  interact  with  host-backed storage  by  introducing  a  shared  PCI  bar window  between  the  guest  and  host  memory Under  this  mechanism,  the  guest initiates  a  setup  mapping  request  to project  specific  file  ranges  directly into  the  DAX  window. Once  mapped,  the  guest  reads  and  writes directly  to  and  from  the  host's  page cache  using  zero-copy  execution, entirely  bypassing  traditional  fuse protocol  overhead  and  data  copying. Because  files  are  mapped  straight  to host  memory,  the  guest  page  cache  is bypassed  completely.  This  eliminates double  caching,  dramatically  reduces  the memory  footprint  required  per  instance, and  delivers  near-native  IO  performance, making  it  ideal  for  high-density virtualization  environments.
